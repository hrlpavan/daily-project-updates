## 🛠️ Automated Daily Sync Tool

This repository includes a standalone automation script to scan local workspaces, collect git commits, inspect modified artifacts, and compile the daily report:

```bash
# Generate report for today
python3 scripts/sync_daily_updates.py

# Preview report without saving
python3 scripts/sync_daily_updates.py --dry-run

# Generate report for a specific date
python3 scripts/sync_daily_updates.py --date 2026-09-24
```

## 3. Bug Bounty Laboratory Specifications (Kali Linux on ARM64)

* **Hypervisor**: UTM v4+ leveraging macOS Apple Virtualization Framework.
* **Architecture**: Native `aarch64` / `arm64` (eliminating TCG dynamic binary translation overhead).
* **Hardware Allocation**:
  * CPU: 4 Virtual Cores
  * Memory: 4,096 MB RAM (Leaves 12 GB RAM for host macOS operations)
  * Display: VirtIO-GPU with `spice-vdagent` guest utilities for hardware-accelerated 60 FPS graphics and clipboard sharing.
  * Virtual Disk: 35 GB Dynamic (Sparse) Provisioning (Initial footprint ~12 GB).
* **Reconnaissance Tooling**:
  * HTTP Engine: ProjectDiscovery `httpx` + `katana`
  * Asset Enumeration: `subfinder` + `naabu`
  * Vulnerability Scanning: `nuclei` with automated template updates
  * Web Fuzzing: `ffuf` with targeted SecLists subsets (`raft-medium-directories.txt`)
* **Compliance Headers**:
  * HackerOne: `X-HackerOne-Research: <username>`
  * Intigriti: `X-Intigriti-User: <username>`

## 5. A-to-Z Bug Bounty Hunting Tools: Storage Sizing Analysis

Conducted an in-depth forensic storage calculation of the complete toolset featured in Hacker Joe's **["A to Z Bug Bounty Hunting Tools! (HACKING)"](https://youtu.be/d5LzEWqD7iw?si=BqwzuLi9y5YmDKEU)** video and Satya Prakash's **`0xKayala/BugBountyTools`** curated repository.

### Category-by-Category Footprint Calculation:
* **Reconnaissance & Subdomains**: `subfinder`, `amass`, `assetfinder`, `katana`, `hakrawler`, `gauplus`, `waybackurls`, `findomain`, `paramspider`, `sublist3r`, `knockpy`, `chaos` $\rightarrow$ **`~427 MB`**
* **Web Application Testing & Scanners**: `burp suite community`, `owasp zap`, `nuclei` + `nuclei-templates` (8,000+ signatures), `sqlmap`, `xsstrike`, `dalfox`, `kxss`, `crlfuzz`, `nikto`, `whatweb` $\rightarrow$ **`~2.70 GB`**
* **API Security Testing**: `postman`, `kiterunner` + Assetnote routes datasets (`routes-large.kite`), `jwt_tool`, `graphqlmap`, `nosqlmap` $\rightarrow$ **`~1.40 GB`**
* **Fuzzing Tools**: `ffuf`, `gobuster`, `dirsearch`, `wfuzz` $\rightarrow$ **`~160 MB`**
* **Network & Port Scanners**: `nmap`, `masscan`, `rustscan`, `zmap`, `netfuzzer` $\rightarrow$ **`~205 MB`**
* **Heavy Exploitation, Cloud & Mobile**: `metasploit framework` (2.2 GB), `commix`, `routersploit`, Cloud tools (`pacu`, `scoutsuite`, `cloudbrute`), Mobile (`mobsf`, `frida`, `objection`, `apktool`) $\rightarrow$ **`~5.55 GB`**
* **Wordlists (Uncompressed)**: `seclists` (8.5 GB uncompressed), `rockyou.txt` (400 MB) $\rightarrow$ **`~9.00 GB`**

### Sizing Recommendations:
* **Lean Bug Bounty Web Arsenal (Tier 1)**: **`~5.5 GB`** (covers 95% of target vulnerabilities on HackerOne and Intigriti).
* **Full A-to-Z Arsenal (Tier 3)**: **`~20.0 GB`** (requires dynamic virtual disk provisioning of 35 GB to prevent host SSD exhaustion).
